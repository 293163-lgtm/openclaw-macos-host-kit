# openclaw-macos-host-kit v0.1.0

Initial public release of `openclaw-macos-host-kit`.

This release packages a field-tested macOS OpenClaw workstation setup flow:

- Terminal-hosted OpenClaw host entrypoints
- optional `OpenClaw Host.app`
- desktop workbench generation
- permission guidance command
- real heartbeat on/off controls
- dry-run and JSON output
- safe archive flow for replacing old desktop workbenches

## Validation

This version was validated through:

- local dry-run generation
- local isolated heartbeat-only generation
- real-machine rollout on Ming's Mac
- second-machine validation on `skymini`
- heartbeat OFF/ON verification showing `disabled (main)` and `30m (main)`

## Boundaries

This skill does not silently grant macOS TCC permissions. It provides operator-safe guidance, launchers, and verification helpers.

## Asset

Download `openclaw-macos-host-kit.skill` from this release and install it into your OpenClaw skills directory.
